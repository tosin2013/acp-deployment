# Reference: extra-vars.yml configuration parameters

All user-facing configuration for a cluster deployment is expressed in a single `extra-vars.yml` file. Example files live in `examples/<topology>/extra-vars.yml`.

Parameters are grouped by the section they appear in.

---

## Top-level parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `architecture` | string | — | Cluster topology. `ha` = 3-node compact HA; `non-ha` = SNO. **Required.** |
| `external_dns` | boolean | `false` | When `true`, Route53 manages external DNS records (IBM Cloud path). When `false`, BIND-in-Podman runs on the helper (bare-metal path). |
| `install_openshift_virtualization` | boolean | `false` | When `true`, `site-post-install.yml` installs the OpenShift Virtualization operator. Requires 48 GiB RAM per node minimum. |
| `workshop_dns_zone` | string | — | The Route53 hosted zone name (e.g., `example.com`). Must match `openshift.base_domain`. Required when `external_dns: true`. |
| `aws_region` | string | `us-east-1` | AWS region where the Route53 hosted zone resides. |

---

## `dns` block

Used only when `external_dns: false`. Configures the BIND-in-Podman DNS server on the helper node.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `dns.network` | CIDR string | — | Machine network CIDR (e.g., `10.0.100.0/24`) |
| `dns.subnet_mask` | integer | — | Subnet mask prefix length (e.g., `24`) |
| `dns.listen_address` | string | — | IP address for BIND to listen on (helper node IP) |
| `dns.upstream_servers` | list of IPs | — | Upstream DNS resolvers (e.g., `[8.8.8.8, 8.8.4.4]`) |
| `dns.network_interface` | string | — | Network interface name on the helper facing the cluster |
| `dns.acls` | list | — | Named ACLs for zone access control |
| `dns.forwardRecords` | list | — | A records for cluster nodes, API VIP, ingress VIP |
| `dns.reverseRecords` | list | — | PTR records for reverse DNS lookup |

## `openshift` block

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `openshift.version` | string | `stable` | OCP release channel or pin. `stable` = latest stable. Pin a specific version for reproducibility (e.g., `4.21.18`). |
| `openshift.cluster_name` | string | — | Short cluster name, no dots (e.g., `acp`). Used to construct DNS names and local paths. **Required.** |
| `openshift.base_domain` | string | — | DNS domain under which the cluster lives (e.g., `example.com`). **Required.** |
| `openshift.pull_secret` | JSON string | `''` | Red Hat pull secret JSON. Populated by `hack/setup-cluster-vars.sh`. **Required.** |
| `openshift.ssh_pub_key` | string | `''` | SSH public key for node access. Populated by `hack/setup-cluster-vars.sh`. **Required.** |
| `openshift.api_address` | IP string | — | Internal VIP for the Kubernetes API server. Must be on the machine network. |
| `openshift.ingress_address` | IP string | — | Internal VIP for the OCP ingress router (`*.apps`). Must be on the machine network. |
| `openshift.cluster_network.cidr` | CIDR | `10.128.0.0/14` | Pod network CIDR. Must not overlap with machine or storage networks. |
| `openshift.cluster_network.host_prefix` | integer | `23` | Per-node pod subnet prefix length. |
| `openshift.machine_network.cidr` | CIDR | — | The network CIDR for cluster node IP addresses. **Required.** |

### `openshift.control_nodes[]` (list)

Each entry defines one control-plane node.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | string | Node hostname (e.g., `control-0`). Must match DNS forward records. |
| `installation_device` | string | Block device path for OS installation (e.g., `/dev/vda` for KVM, `/dev/nvme0n1` for bare-metal). |
| `networking.interfaces[]` | list | Per-interface NIC configuration (nmstate format). |
| `networking.interfaces[].name` | string | Interface name inside the node (e.g., `eth0`, `bond0`). |
| `networking.interfaces[].mac_address` | string | MAC address. For KVM: generated by `hack/generate-kvm-macs.sh`. For bare-metal: from hardware labels. |
| `networking.interfaces[].type` | string | `ethernet` (default), `bond`. |
| `networking.interfaces[].ipv4.address[].ip` | string | Static IP for this interface. |
| `networking.interfaces[].ipv4.address[].prefix_length` | integer | Subnet prefix (e.g., `24`). |
| `networking.interfaces[].link_aggregation.mode` | string | Bond mode (e.g., `802.3ad` for LACP). Bare-metal only. |
| `networking.interfaces[].link_aggregation.ports[]` | list | Physical NIC names to bond (e.g., `[eno1, eno2]`). |

### `openshift.all_node_settings`

Shared settings applied to all nodes.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `dns_resolvers` | list of IPs | — | DNS server IPs configured on all nodes. |
| `routes[].destination` | CIDR | — | Route destination (e.g., `0.0.0.0/0` for default route). |
| `routes[].next_hop_address` | IP | — | Gateway IP. |
| `routes[].next_hop_interface` | string | — | Interface for this route. |
| `public_interface` | string | — | Primary network interface name (cluster + management traffic). |
| `storage_interface` | string | — | Interface name for ODF storage network. `eth2` (KVM) or `bond1` (bare-metal). |
| `storage_network` | CIDR | — | Storage network CIDR (e.g., `192.168.52.0/24`). Used by ODF when `odf_use_multus: true`. |
| `odf_use_multus` | boolean | — | `false` for KVM (virtio does not support macvlan). `true` for bare-metal (dedicated bond for ODF). **Required — no default.** |
| `odf_device_count` | integer | — | Number of ODF block devices total across all nodes. `6` for KVM (2 disks × 3 nodes). `12` for typical bare-metal (4 disks × 3 nodes). **Required — no default.** |

## `acme` block

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `acme.solvers` | list | `[route53]` | ACME DNS-01 solver(s). Supported: `route53`, `cloudflare`. |

## `zerossl_account` block

| Parameter | Type | Description |
|-----------|------|-------------|
| `zerossl_account.email` | string | ZeroSSL account email address. |
| `zerossl_account.kid` | string | ACME External Account Binding (EAB) Key ID from [app.zerossl.com/developer](https://app.zerossl.com/developer). |
| `zerossl_account.key` | string | ACME EAB HMAC key. Treat as a secret — do not commit to git. |

## Environment variables read at runtime

These are not in `extra-vars.yml` but are read by Ansible from the environment.

| Variable | Used by | Description |
|----------|---------|-------------|
| `AWS_ACCESS_KEY_ID` | `update-ocp-ingress-cert.yml` | AWS credentials for Route53 DNS-01 |
| `AWS_SECRET_ACCESS_KEY` | `update-ocp-ingress-cert.yml` | AWS credentials for Route53 DNS-01 |
| `KUBECONFIG` | All post-install playbooks | Path to cluster kubeconfig |
| `BAREMETAL_BMC_PASSWORD` | `hack/deploy-on-baremetal.sh` | BMC password for Redfish API |
| `BAREMETAL_BMC_INSECURE` | `hack/deploy-on-baremetal.sh` | `true` to skip BMC TLS verification (self-signed BMC certs) |
